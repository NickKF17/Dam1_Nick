let variable para introducir una variable.

prompt() para que salga un panel para introducir datos por teclado.

confirm() para soltar una advertencia de aceptar y cancelar.

Math.round() para redondear.

cadena.toLowerCase() conversion a minusculas.

for (let i=n; i<=n; i++) es la sintaxis del bucle for.

array.push(dato) funciona como el .add de Java.

array.pop(dato) funciona como el .remove de Java.

array.indexOf(dato) devuelve la última posicion del dato.

array.includes(dato) devuelve true si esta el dato y false al contrario.

array.sort() y array.reverse() para ordenar ascendente y descendentemente.

Math.random() * (fin-inicio+1)+inicio para generar un número aleatorio.

ParseInt() convierte el valor dentro del paréntesis a entero.

let array = [] para crear un array de longitud VARIABLE.

"<br>" para saltos de linea en HTML y en Text es \n.

Math.max(...array) y Math.min(...array) para sacar el máximo y el mínimo.

cadena.charAt(n) para devolver el caracter de la posicion n de la cadena.
